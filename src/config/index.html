    How it works

    KawKaw emerges halfway along a track you place in Settings, and chat decides which way it goes. Every second, the votes that arrived in that second are added up: !call pulls KawKaw one step toward you, !shoo pushes it one step toward the flee end. Only the net result counts, so 6 calls and 4 shoos in the same second move it 2 steps toward you.

    The track runs from −10 (flee) through 0 (where it appears) to +10 (lick). Three ways it can end:

    • Lick — chat gets it to +10. KawKaw licks you, then digs away.
    • Flee — chat gets it to −10. KawKaw slides off the screen the way it came.
    • Confused — the session timeout runs out with the meter stuck in between. A ? appears and KawKaw digs away.

    One viewer cannot decide it alone: each person's messages are capped per second, so spam is welcome but soloing the meter is not. Saved changes take effect at the next KawKaw, never mid-encounter — except position, orientation, and volume, which apply immediately so you can adjust them while looking at the overlay.
