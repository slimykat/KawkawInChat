KawKaw

How it works

KawKaw emerges halfway along a track you place below, and chat decides which way it goes. Every second, the votes that arrived in that second are added up: !call pulls KawKaw one step toward you, !shoo pushes it one step toward the flee end. Only the net result counts, so 6 calls and 4 shoos in the same second move it 2 steps toward you.

The track runs from −10 (flee) through 0 (where it appears) to +10 (lick). Three ways it can end:

  • Lick — chat gets it to +10. KawKaw licks you, then digs away.
  • Flee — chat gets it to −10. KawKaw slides off the screen the way it came.
  • Confused — the session timeout runs out with the meter stuck in between. A ? appears and KawKaw digs away.

One viewer cannot decide it alone: each person's messages are capped per second, so spam is welcome but soloing the meter is not. Saved changes take effect at the next KawKaw, never mid-encounter — except position, orientation, and volume, which apply immediately so you can adjust them while looking at the overlay.

Session start

How KawKaw gets summoned.

Only rewards whose name contains this text start an encounter, so "Summon KawKaw!" matches "KawKaw". Case doesn't matter. Leave it blank to let any reward summon KawKaw.

Meter feel

With decay at 0 the meter keeps whatever chat gives it, so a lick takes 10 net calls in total — raise push per message for a quiet chat, lower it for a busy one. Any decay above 0 makes the meter sag back toward the middle each second, so chat has to sustain the pressure instead of just accumulating it.

How long an ending stays on screen — the lick, or the confused question mark — before KawKaw digs away and the overlay clears.

Audio

KawKaw's voice clips, played through the overlay. Takes effect on the next clip, so you can set it by ear during an encounter.

Overlay position

The two ends of the track, as 0–1 fractions of the overlay (0 = left/top, 1 = right/bottom). KawKaw appears midway between them and slides toward whichever end chat pushes it to.

Preview

Solid = where KawKaw appears. Ghosts = the two ends it can be pushed to. Reflects current values, including facing and rotation.
