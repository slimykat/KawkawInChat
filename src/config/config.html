KawKaw

How it works

Viewers type !call and !shoo in chat to push KawKaw toward licking the streamer or fleeing. Reaching +10 is a lick, −10 is a flee. Changes here take effect at the next KawKaw appearance, so retuning never disturbs an encounter already in progress.
